# Operating Procedure — PCBA 444-027654-003 (RF Driver Board)

## Setup
1. Install board in shielded enclosure EN-RF-01.
2. Terminate RFout into a 50-ohm load before power-on.

## Operation
1. Apply 12 VDC bias; confirm no thermal fault.
2. Enable the driver stage via SW1.
3. Monitor forward/reflected power on the directional coupler.

## Shutdown
1. Disable SW1, remove RF drive, then power down.
2. Allow the heatsink to cool before handling.
