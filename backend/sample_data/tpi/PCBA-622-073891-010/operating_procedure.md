# Operating Procedure — PCBA 622-073891-010 (Sensor Interface Breakout Board)

## Setup
1. Mount the board on the interface test bench.
2. Connect sensor emulator to the analog input header.

## Operation
1. Apply 5 VDC at J3; confirm the isolated secondary rail.
2. Drive analog inputs from the emulator and observe passthrough.
3. Read digital I/O states from J6.

## Shutdown
1. Remove sensor drive, then power down.
2. Disconnect the emulator before removing the board.
